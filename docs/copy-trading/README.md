# OKX 跟单榜单（copy trading）：数据线侦察与前向跟踪

本页回答两个问题：OKX 上的「明星带单员」成绩单是什么口径、值不值得跟；以及这条线的
数据怎么落、怎么验收、怎么在前向验证里定生死。

所有读数取自首份快照（2026-10-16，`dataVer 20261016230001`，246 名 SWAP 带单员），
落盘路径 `data/storage/okx_copy/raw/lead_traders/2026-10-16.jsonl`，读数可用
`scripts/fetch_okx_copy.py --list-only` 与验收闸重放核对。

## 一、结论速览

- **榜单不是骗局，是口径**：榜上的「收益率」是**交易员自有投入资金**的累计收益率
  （`pnlRatio ≈ pnl / investAmt`），不是跟单者的收益；跟单者赚多少在另一个字段
  `curCopyTraderPnl`。同一批人、两份成绩单，差一个量级。
- **「明星」是少数**：246 人里 **113 人一个跟单者都没有**；现存跟单者 ≥100 人的只有
  **23 人**，合计跟单资金 22.2M USDT。中位数是「自有投入资金 28.2 万 USDT、累计盈亏
  6,785 USDT、AUM 50 USDT」——榜单按自有大账号排，不是按受欢迎程度排。
- **平台在发高波动彩票**：246 人里 **65 人（26%）累计亏损**照样挂在榜上；正收益高度
  集中（前 10 人占 47%、前 20 人占 63%）。这就是排序选择出来的极值，不是可重复的经验
  概率——与凯利问题同构：分母（退榜/爆仓的人）与 p（跟单者自己的进入时点）都不可见。
- **跟单者的实际成绩单显著更差**：AUM ≥ 1 万 USDT 的 59 人里，交易员自报收益率中位
  **+19.2%**（78% 为正），跟单者口径中位只有 **+6.0%**（56% 为正）、汇总口径
  `Σ curCopyTraderPnl / Σ aum = +6.5%`。反例（自报为正、跟单者亏钱）大量存在：
  `Faithful-Punk-Fuse` 自报 +207% / 跟单者 −17,350，`日赚一妹` 376 人在跟 / 跟单者
  −103,896，`RealCryptoFox` 306 人在跟 / 跟单者 −165,518。
- **引流结构与容量不对称**：`HCSD` 用 5,429 USDT 自有资金打出 25.9×、跟单资金
  603,912 USDT（≈111 倍）；小账号高杠杆成绩单是大 AUM 的入口。
- **留存极低**：累计跟单人次 ≥100 的 89 位，现存/累计中位 **4.5%**（如 RealCryptoFox
  累计 27,407 人、现存 306）。累计数含重复关注/取关，不能当流失率原样读，但量级说明
  跟单关系普遍很短。
- **风险结构**：日序列（122 人拿到 ≥20 个点；上游对老号给 90 点、新号只给 19 点）
  最大回撤中位 **−8.5%**、P10 −44.0%，**8 人 >50%**、最惨 −76.9%；最差单日中位
  −3.71%、P10 −22.1%；胜率 ≥60% 且回撤 >40% 的「马丁指纹」5 人（`mingdashi`：
  20 天胜率 68.6%、最差单日 −46.1%、回撤 −73.4%；`KYRR Ai` 胜率 84.6%、回撤 −60.3%）。
- **激励不一致**（官方规则，见 §五）：带单员按等级最高拿**跟单者盈利的 30% 分润**
  （周结），合约带单的「铜牌」门槛是**带单投入资金 ≥ 100,000 USDT**（与实测
  `investAmt` 的 P10 = 104,235 对得上）。带单员的最优解是 **AUM × 波动**，跟单者的
  最优解是低费用低换手——两者目标函数不一致，加上跟单滑点/延迟与分润，榜面收益对
  后来者不可复制。

## 二、榜单字段口径（实测核对）

| 字段 | 口径 |
| --- | --- |
| `pnlRatio` | **交易员自有投入资金**的累计收益率；217 个非退化样本里 97% 满足 `pnlRatio ≈ pnl / investAmt`（相对误差 <1%） |
| `investAmt` | 自有投入资金（90 天滚动口径的统计字段）；官方带单门槛 10 万 USDT 与其实测 P10 = 104,235 一致 |
| `pnl` | 该账号累计盈亏（USDT），榜单默认就按它排序——**收益率第一的 `HCSD` 只排在第 87 位** |
| `curCopyTraderPnl` | **当前跟单者**的累计盈亏（平台口径，不是带单员的） |
| `winRatio` | 90 天日胜率（`lastDays=3` 时与榜单字段逐位一致） |
| `aum` | 跟单资金规模（可远大于交易员自有资金） |
| `copyTraderNum` / `accCopyTraderNum` | 现存 / 累计跟单人次（后者含重复关注取关） |
| `history` | 上游附带的日度收益序列，实测长度是双峰：老号 90 点、新号只给 19 点（首份快照里 102 人生 90 点、117 人生 19 点，另几个人 3~45 点） |

端点（公开、免鉴权；本机直连不通，走 `OKX_USE_PROXY` 的代理）：
`public-lead-traders` 每页 10 人、`page` 从 1 起；`public-stats` 的 `lastDays` 只接受
1/2/3，分别是 7/30/90 天滚动口径（传 7/90 报 51000）。字段全为字符串，空值给 `""`。

## 三、数据契约与作业

```
data/storage/okx_copy/raw/lead_traders/<YYYY-MM-DD>.jsonl
data/manifests/okx_copy_raw_lead_traders.json
```

- 业务键 `(uniqueCode, dataVer)`：**榜单版本没动时重跑不写重复行**（平台榜单
  `dataVer` 在本地 23:00 前后刷新），版本动了就再留一份；raw 只增不改。
- 每行保留：榜单标量与 `history`；上游的 `traderInsts` 只留个数
  （`instrumentNum`）——最长能挂 283 个标的、占整份文件七成字节，对跟踪没有增量信息。
- 采集：`uv run python scripts/fetch_okx_copy.py`（单人统计失败不中断整批，缺统计在
  验收闸里报告警）；只落榜单不落统计用 `--skip-stats`，只看不写用 `--list-only`。
- 验收：`uv run python scripts/audit_okx_copy.py`（致命=数据不信：解析失败、键重复、
  核心字段缺失或越界、manifest 与磁盘不符；告警=数据可能不全：快照过期、人数缩水、
  缺统计、`pnlRatio ≈ pnl/investAmt` 漂移）。
- 计划任务：`nerd-trader-copy-daily` 每日 23:40（榜单 23:00 刷新后 40 分钟），入口
  `bash scripts/scheduled_run.sh copy`（采集 + 验收），日志按天落
  `logs/scheduled/copy-<日期>.log`。

## 四、前向跟踪判据（预注册，2026-10-17 首份快照前写定）

榜单每天换人，**回看没有分母**（退榜/爆仓的看不到）。因此判据只作用于采集期内新增的
快照，不用首日附带的 `history`：

- **样本**：每日快照里 `copyTraderNum ≥ 100`、`leadDays ≥ 90` 的带单员，等权。
- **两个口径分开记**：
  1. `R_leader`：按每人 `pnlRatio` 日变化等权复利——「跟着榜单买」的上界（不含滑点、
     延迟、分润）；
  2. `R_copier`：按 `Σ curCopyTraderPnl / Σ aum` 的日变化——平台给出的跟单者实际口径。
- **基准**：BTC 买入持有（`data/storage/crypto/okx/spot/1d` 日线收盘，等权起点对齐）。
- **判定（到期不得修改）**：到期取 2027-10-17，或样本内全部标的退榜导致数据断供时提前
  收官。满足任一即判「榜单不可跟」：`R_copier` 的年化中位 ≤ 0；或 `R_copier` 显著低于
  `R_leader`（配对 bootstrap 95% 区间不含 0，说明漏损吃掉了榜面收益）；或期初/期末
  top-20 的收益排名相关性 ≈ 0（榜单只是近期极值）。
- **纪律**：中途改判据必须记录在案，并把已有前向样本作废重新起算。

## 五、已知限制

- **幸存者偏差**：平台只列当前带单员，爆仓/退榜的看不到，榜单读数天然乐观。
- **无跟单者级明细**：`curCopyTraderPnl` 是当前跟单者的汇总，看不到每人何时进入/退出，
  「某天开始跟」的收益只能近似。
- **平台口径可改**：`investAmt` / `curCopyTraderPnl` 的定义由平台控制，验收闸用
  `pnlRatio ≈ pnl/investAmt` 盯漂移，但改口径仍是系统性风险。
- **成本只估上界**：没有 L2 盘口，跟单滑点与分润只能用 `R_leader − R_copier` 的实测差
  来事后度量。
- 本数据集与 crypto 行情一样由本项目自持（不入容器数据湖，参照容器 ADR-0006 的自持
  精神），与加密行情无关，只是 OKX 平台侧的另一类数据。
