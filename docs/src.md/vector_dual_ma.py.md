# 自适应双均线策略 (Adaptive Dual MA Strategy)

## 状态识别器：牛市与熊市的切换

策略基于 MA120 (半年线) 将市场划分为两种状态，自动切换战术：

牛市状态 (Price > MA120)：启用激进参数，只做多，捕捉主升浪。

熊市状态 (Price < MA120)：启用防御参数（实际上是休眠模式），空仓观望，不做空也不抄底。

## 牛市策略参数

策略行为画像
2021年 (大牛市)：价格站上 MA120，策略火力全开，利用 14/25 的敏锐度频繁捕捉上涨波段，ADX=30 保证了只做主升浪。

2022年 (大熊市)：价格长期低于 MA120，策略检测到熊市，试图调用熊市参数，但被 ADX=100 拦截。结果：全年空仓，完美躲过暴跌。

2023年 (猴市/震荡)：价格反复穿梭 MA120。

站上去时：试错开多，如果趋势不强（ADX<30）不开单；如果趋势强但随后跌破，止损离场。

跌下来时：立刻切回空仓模式。

这是策略磨损最大的阶段，但也是为了不错过后面大行情的必要成本。
