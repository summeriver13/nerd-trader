## 2. 核心命题：金融 ML 不是通用 ML

通用 ML 的前提是 IID 样本。金融数据**处处违反**这个前提：

| 通用 ML 假设 | 金融现实 |
| --- | --- |
| 样本独立同分布 | 标签由重叠的未来收益决定，天然不独立 |
| 特征与标签一一对应 | 一个标签横跨多期观测，无法归因 |
| 训练集与测试集可分 | 序列相关 + 标签重叠 → 泄漏 |
| 特征平稳 | 价格有记忆但不平稳，收益平稳但无记忆 |
| 可以反复用同一份数据 | 反复用同一份数据 = 数据挖掘 |

**所以金融 ML 的失败不是因为模型不够强，而是因为验证环节被系统性破坏。**
他的整套方法论（DSR、PBO、purge/embargo、唯一性权重）都是为修复验证环节而设计的。

## 4. 核心工具（按本仓库的优先级排）

### 4.1 PBO / CSCV —— 唯一可识别的“我过拟合了吗”

**做法**：把 N 个候选策略的收益矩阵切成 S 块；每种“S/2 块作训练、其余作测试”的组合，
找出训练集里最优的候选，看它在测试集里的排名是否跌破中位数。
**PBO = 跌破中位数的比例。**

**为什么它比“校正门槛”重要**：见 §5。FDR 无法从样本内统计量识别，但 PBO 是**可估的**——
它不需要知道“有多少个真效应”，只需要问“选出来的那个在没见过的数据上还排得上号吗”。

### 4.2 Purged K-Fold CV + Embargo

purge：把标签时间区间与测试集重叠的训练样本剔除。
embargo：再禁运测试集之后紧邻的一小段（h≈0.01T），因为序列相关会让边界处的样本泄漏。
**本仓库完全没有这一层。**

### 4.3 Dollar Bars

**为什么时间棒最差**：信息不是按恒定熵率到达的。按固定时间采样，每个观测的信息含量相差极远，
导致（a）收益序列自相关（b）异方差（c）统计性质差。
**为什么美元棒最好**：按成交金额累积采样，采样频率天然稳定（作者用 E-mini S&P 500 三种棒对比过）。

**对本仓库的特殊意义**：1m 数据已在本地（30 只永续、6100 万根），美元棒**可以直接构建**，
且它能回答一个当前无法回答的问题——**“3 根反转”这个尺度是信息尺度还是日历尺度？**

### 4.4 Triple-Barrier + Meta-Labeling

三重障碍：止盈、止损、时间三道障碍，先碰到哪道就取哪道的标签（把**路径**纳入标签）。
元标签：主模型只定**方向**，次模型定**要不要出手、出多大手**（0 到 1 的仓位）。

**对本仓库的特殊意义**：核心结论是“反转有边际但被 taker 成本吃掉，maker 条件化挂单能救回一部分”。
元标签回答的正是“给定主信号，这次该不该出手”——与条件化挂单**是同一个问题**，
但有一套现成的建模框架，而不是手写一个挂单探针。

**本仓库的落地口径（2026-10）**：`src/research/meta.py` + `scripts/meta_label_study.py`。
关键修正是 **embargo 必须按天计**——旧实现传的是 200 个观测，在这个真实帧上（168,442
观测 / 2,292 天、每日中位 68 行）只隔约 2.9 天，而 `0.01T` 在这个帧上是 8 天。改成按天
（默认 8 天、训练集切到整天边界）后复跑，结论一条没翻、读数小幅移动：0.60 档 lift
+153 ~ +216bp（原 +146 ~ +254bp）、命中率 0.586 ~ 0.593，账本仍 N=6653。
与 `src/research/tuning.py` 是同一条纪律：purge/embargo 的单位在面板上只能是**天**。

**Ch 3.6 趋势扫描标签（2026-10）**：固定期限与三重障碍之外还有第三条路——标签取
「前向窗口内 |t| 最大的趋势」的符号（`labels.trend_scan`；向量化实现：斜率 t 值等于
相关系数的单调变换 `r·sqrt((j−2)/(1−r²))`，整批窗口一次算完），Ch 3.7 再把方向与
仓位都交给模型。实测的关键是**分清两层**：标签自己的方向每注 +445bp、命中率 73%，
但那是用了未来窗口的**上界、不是策略**；把方向也交给模型后（AUC 0.49、全下每注
−0.61bp）比主因子（+13.06bp）更差，即**信息不在特征里**。三条口径值得记：标签不能
当方向；对照臂只在标签可用行上评估；带动态阈值时「弱趋势」要当负类而不是删行
（删行＝用标签决定哪些行下注，等于前视）。

### 4.5 Sample Uniqueness

平均唯一性 ūᵢ = 标签存活期内 1/concurrency 的均值；样本权重再按可归因的绝对对数收益加权。
**对比本仓库**：`iloc[::horizon]` 是“丢弃”，唯一性加权是“打折”——后者不丢数据、且**没有偏移自由度**。

### 4.6 Fractional Differentiation

把价格差分到 d<0.5，得到**既平稳又保留记忆**的序列。作者原话：
“多数金融研究基于 d=1 的收益率，意味着几十年来大部分金融研究建立在**过度差分（无记忆）**的序列上，
导致虚假预测与过拟合。”

**本仓库已试（2026-10）**：`src/research/ffd.py`（只做固定窗版本，展开窗是作者自己
否定的形式）+ 因子库 `ffd_d0p2`/`ffd_d0p4`。工具层面作者主张成立（BTC 日线：水平不过 ADF，
d=0.25 起通过而「与水平的记忆」仍有 0.987，d=1 塌到 0.02）。但三处原文没说：
**默认阈值 1e-5 是分钟级口径**（日线同阈值要 1457 根历史）、**截断使权重和不再为 0
⇒ 价格水平泄漏进特征**（原始变换与对数水平的截面相关 +1.000，截面标准差比信号大 13~35 倍）、
去掉泄漏后它其实是**短周期反转**（IC t 13.1；控制 `mom_7` 后残差 t 10.1，不是动量的
重新包装，但与 `rev_3` 同一量级）——落在成本墙那一侧。

**收尾（2026-10）**：已接进扫描器（`ffd` 族，d=0.10~0.90 稠密轴）——两个市场都过
平台门槛（h=1 时 81 个 d 值全过、最低 |t| 7.7），但**收益层每期价差为负、DSR 两市场
都不过**（最好 0.0096），PBO 短期限 38%~59%。机制是中位数排序换不成均值口径的等权
价差（最高分位中位 −72bp 而均值 +6.1bp，`mom_7` 同形）。账本 N 6625 → 6634。
详见 README 第十四节。

### 4.9 超参调优（Ch 9）

原文的四条片段：拿 **purged K 折**做内层 CV 的网格搜索（Snippet 9.1）、能透传
`sample_weight` 的增强 Pipeline（9.2）、随机搜索（9.3）、**log-uniform** 分布（9.4）。
核心主张是两件：**搜索的折必须 purge/embargo**，以及**选超参本身就是一条多重检验轴**
（在 K 个配置里挑最好，与在 K 个策略里挑最好没有区别）。

**本仓库已实现（2026-10）**：`src/research/tuning.py`（`PurgedKFold` 按**日期**切折、
`search_hyperparameters` 随机/网格搜索、`log_uniform`、`scoring_for`、`positive_f1`）+
实证脚本 `scripts/tuning_study.py`；`meta.py` 顺手拆出 `build_classifier`，让超参定义只有
一处（调参要的是「按参数造模型」，不是「造好顺便训了」）。

**实测结论（元标签分类器、两市场各四折）**：CV 抬高**稳定到几乎一样**（都是 +0.033），但
样本外只拿回三分之一到一半（+0.011 / +0.016）且**逐折符号会翻**（8 折里 3 折为负）；
CV 最优几乎从来不是样本外最优（事后最优平均再高 +0.013）；CV 排序与样本外排序的 Kendall τ
在两市场不一致（spot +0.66 全正、swap +0.39 含一折负）。**CV 的改善不能按面值兑现。**

副产物两条原文没说、跑出来才发现的坑：**某折里没有正类时 f1 恒为 0、预测什么都一样**
（这种折对调参零信息）；**purge/embargo 的单位随数据形态变**——单序列是观测数，本仓的面板
必须是天数，否则等于没挡同日泄漏。

**把钱接上（Ch 9 接 Ch 10）**：同一批样本外概率喂进 Ch 10 的下注管线后，逐折净夏普差 8 折里
4 正 4 负（均值 +0.020 / −0.008）——**调参在钱上也是零**。顺带量出元标签过滤臂唯一稳定的贡献
是**省成本**（换手比「全下」低 20~60 倍，方向信号本身没被改善），并抓出一条读法陷阱：各折
拼成一条再算夏普会被平盘日稀释，连符号都会翻。详见 README 第十七节。

### 4.8 HRP / 分层风险平价（Ch 16）

马科维茨的 `w ∝ Σ⁻¹μ` 在相关簇上会把估计误差放大成极端权重（「马科维茨诅咒」）；
HRP 的对策是**把协方差变成一棵树**：先聚类，再自顶向下按簇方差分配，全程不求逆矩阵。

**本仓库已实现（2026-10）**：`src/research/allocation.py`（距离 `√((1−ρ)/2)`、单链接、
准对角化、逆方差、递归二分、`hrp_weights`）+ 实证脚本 `scripts/hrp_study.py`。
准对角化用深度优先展开替代原文的迭代插入法，**等价性由用例对着原文算法逐字比对钉死**；
距离与聚类口径与 `importance.tools.feature_clusters` 收敛成一份实现。

**实测结论（七因子策略层组合，协方差只用训练段）**：等权组合拿到本仓库最好的记录
（PSR 0.930 / 0.951，MinTRL 1339 / 1135 对可用 1080 / 1147，仍差一点），但
**等权 / 逆方差 / HRP 三者差异在噪声内**；原文「HRP 样本外方差更低」只在 swap 成立
（spot 上 HRP 反而最高）。另钉住一处真实弱点：递归二分的切分层次进了权重，
三只完全相同的资产拿到 1/4、1/2、1/4 而非等权——原文 `getRecBipart` 就是如此，
但它意味着簇内权重会随列顺序与样本漂移。详见 README 第十六节。

### 4.7 回测统计量与策略风险（Ch 14/15）

DSR/PBO 回答“试了这么多次还算不算技能”；Ch 14/15 回答“**这条记录本身厚不厚**”：
PSR（夏普高于基准的概率）、MinTRL（达到 95% 置信所需的最小观测数）、回撤与水下时间、
逐期收益的集中度（HHI），以及给定下注规则时的所需胜率 / 所需下注次数 / 失败概率。

**本仓库已实现（2026-10）**：`src/research/track_record.py` 与
`src/research/strategy_risk.py`，已接进 `scripts/factor_verify.py` 常规输出。

**实测抓出两处原文口径问题**（跑真实数据才暴露，读原文读不出来）：

1. **集中度只在同号收益上有意义**：权重是 `r/Σr`，混号时权重会超 1 甚至变负。
   直接嗂逐期多空价差得到 9.5 / 14.4 / 40.6 这种假数（`[0.5,−0.3,0.2,−0.1,0.05]` 给 3.755）。
   原文的对策是分正负两支算，本仓改成混号直接报错、由 `concentration_by_sign` 分。
2. **`binFreq` 的增根检验量纲错了**：原文写作 `isclose(binSR(sl,pt,freq,p), tSR)`，
   左边是**胜率**、右边是**夏普**，几乎永远不成立（书里的 `main()` 走 `probFailure`，
   恰好绕过这一行）。按本意改成「反解回的胜率必须等于给定胜率」。

另：`probFailure` 把 `p(1−p)` 直接当**标准差**（自注为 bootstrap 近似），本仓照原文
实现、不冒充精确值。

**主结果**：两个市场、11 个平台代表候选，**没有一个 `vol` 候选的记录够长**——
swap 六个期限的 PSR 只有 0.52~0.71、MinTRL 是期数的 14~1200 倍；唯一够长的是现货
`dth@h7`（PSR 1.000 / 0.988，MinTRL 80 / 176 对 327 期）。而**市场等权买入持有**的
PSR 是 0.951（swap）/ 0.914（spot）。逐期集中度全 ≤ 0.145，说明盈亏不是靠几期暴利
撑起来的；失败概率在 0.41~0.69（目标年化夏普 1.0）。详见 README 第十五节。

### 4.10 组合式 purged 交叉验证与回测路径（Ch 12）

把「一个数」变成「一个分布」的工具：时间轴切 N 组、每次 k 组做测试（C(N,k) 次切分），再拼成
φ = C(N,k)·k/N 条覆盖全时段的回测路径。价值不在提高精度，而在**让点估计的排序可被检验**——
本仓用它复查第 16 章的三种配权：单次切分在现货上说 HRP 最好（年化 1.202 / 0.943 / 0.782），
9 条路径说**正好反过来**（1.123 / 1.063 / 0.889），逆方差最优、HRP 垫底；换 N=8/12 后

「逆方差 > HRP」两市场都稳。

两处口径必须记牢：原书派生的 mlfinlab 实现把 `self.embargo = 0` 写死在主循环里（等于没有
embargo，本仓不照抄）；CPCV 的训练组含测试组**之后**的日期，所以路径分布衡量的是**参数估计

### 4.11 微观结构特征（Ch 19）

原文主张用微观结构量（有效价差、Kyle λ、Amihud、VPIN）把「成本」从假设变成实测。本仓照做，
覆盖 30 个有 1m 缓存的标的，结论有取舍：**成本假设确实偏高一倍**（实测单边 5.0~5.4bp，
其中 5bp 是手续费、价差仅 0.2~0.4bp，而仓里一直按 10bp/边算），但**这些量当不了因子**——
λ 与成交额的秩相关 −0.966（只是流动性的代理）、小币上量级不可信（$1M 冲击 596bp），四个
微观结构因子的分位组合毛收益全部弱于既有 liq_30；VPIN 对次日 |收益| 的秩相关还是**负的**
（−0.082，与原文「毒性→波动」相反），对带符号收益 ≈0。另有一处工程教训：CS 要在 1 分钟
尺度估再取日中位，用日级高低幅时价差会被波动淹没（BTC 半数以上交易日 α<0 被按原文截 0，
会被读成「零成本」）。接回策略线把成本当自变量扫一遍（0~10bp）后：只有三处**边际档**在 5.4bp 下翻正，反转的平衡成本 2.48~4.69bp 仍低于实测——即成本口径影响的是「还差多远」而不是「行不行」。详见 README 第二十二节。

池尾（liq_30 与反转的溢价所在）后来补了 14 只 180 天 1m：**CS 可估日占比中位 0.008**
（1m 覆盖的 30 只同窗口是 0.769、BTC/ETH/SOL 是 1.000），滤掉「不动的分钟」也只救到
0.047——估计量在薄市场结构性失效；Roll 有覆盖率（0.776，往返中位 4.5bp）但与 CS 差一个
量级（BTC 往返 1.7bp 对 0.09bp）、被价格离散污染。日频代理标定同样无信息（留一误差
0.156bp，而训练目标全距 0.22bp）。故 5.4bp 是**乐观下界**，池尾成本只知硬底 5.0bp/边
（taker），而反转（swap h=1）的平衡成本 4.69bp 低于它——即使池尾价差为零那一档也做不了。

### 4.12 熵特征（Ch 18）

`src/research/entropy.py` + `scripts/entropy_study.py`：香农熵（固定宽度分箱）、顺序熵、LZ76 熵率、
Kontoyiannis 最长匹配熵率；两个序列类估计量一律扣**同窗置换基线**。四条钉死的口径：

- **等频分箱是死的**：分位数边界强制每箱等量 → 熵恒等于 log2(箱数)（随机序列与常数序列都给 3.3219），
  信息量为零。必须固定边界。
- **小样本偏置是系统性的**：iid 序列上 LZ 偏高约 5%、Kontoyiannis 偏高约 11%（n=2000），常数序列的
  Kontoyiannis 仍有 0.15——「低熵」读数会在短窗上自己冒出来，基线不可省。
- **Kontoyiannis 只许在前缀里找匹配**：在全序列里找等于用了未来数据，会把熵压低。
- **LZ 的短语数是整数**：window=250 时全池只有 11 个水平、每期截面中位 6 个不同取值，截面排序直接
  失效（排序表被整片跳过）。用它必须先去基线。

结论：熵与既有因子的 |ρ| ≤ 0.03（信息确实是新的），但 IC ≤ 0.006、分位组合净收益全负——
### 4.13 合成数据与多重检验校正（Ch 13 + 书外）

**Ch 13 在本仓唯一有用的部分是「真值已知的零假设床」**——不是造数据让结论好看，而是拿它
标定校正工具。`scripts/corrections_study.py --stage bed` 用「共同因子 + 个体噪声」的 AR(1)
候选族做床（真值已知：无信号），量四种做法的拒绝率（K 个候选 × T 个观测，每格 100 次实验、
bootstrap 199 次）：

- **不校正必然误报**：取最小 p 的拒绝率在 K=15 时 0.59、K ≥ 100 时 1.00（名义 0.05）。
  「从一堆候选里挑最好」这个动作本身就能造出显著性——账本 N=6653 正处在这个格子里。
- **BH 在相关候选下家族级拒绝率 0.27 ~ 0.33**：它管的是 FDR（被拒项里假发现的比例），
  不是「有没有误报」；ρ=0.5 时一个共同因子会让一整块候选同时「显著」。这与 §5 记的
  「FDR 在搜索-选择下不可识别」是两件事，合起来说明 BH 在本仓只配当对照臂。
- **RC / Hansen SPA 贴住名义 α**（0.03 ~ 0.14）而功效 1.00（种 0.4σ 信号）——尺寸控制不是
  靠「一律不拒」换来的。

工具与口径：`src/research/corrections.py`（`reality_check` 不学生化、`hansen_spa` 学生化并
同时给 `p_consistent`/`p_upper`、`naive_p_values` 单侧对照臂、`benjamini_hochberg` 步进），
重采样一律 Politis-Romano 平稳 bootstrap（默认块长 T^(1/3)），零波动候选标准误取 inf 使 t
归零。真实家族读数与「家族级检验必须钉 anchor」那条口径见 README 第二十四节。

## 5. 对本仓库最锋利的一刀：我刚建的因子扫描器错在哪

**背景**：`src/research/factors/sweep.py` 扫了 468 个候选，用“有效试验数”（从 IC 序列相关矩阵的
特征值谱算 N_eff = 3.3）把门槛从名义 Bonferroni 的 3.87 降到 2.46，然后报出 33 个“平台”。

**问题**：de Prado & Fabozzi (2026)《The False Discovery Rate in Finance: **Identification Failure** and
Search-Adjusted Estimation》证明：

> FDR **cannot be identified from in-sample statistics alone** when reported results arise from a
> search-and-selection process.
> —— 当结果来自搜索-选择过程时，FDR 无法仅从样本内统计量识别。

并明确指出：此前那些“从已发表统计量的横截面推断出低 FDR”的方法**不成立，会严重低估真实假发现率**。

**逐条对照**：

1. **不可识别**：N_eff 完全由样本内 IC 相关矩阵导出，正属于被证明不可识别的那一类。
   而且论文说这类方法**低估**假发现率——我的校正方向恰好是**放松**门槛（3.87 → 2.46），即低估方向。
2. **N 不是“我试过的次数”**：N_eff 只数了本次扫描**内部**的冗余，没数历史上试过的所有东西
   （六个因子 × 2 市场 × 多期限、carry、配对、meme、上新币、maker……）。
   DSR 的 N 是“独立试验数”，而“独立”指的是**统计上的独立**，不是“同一次脚本里跑的”。
3. **没有样本外**：平台判据是稳健性的**代理**。§4.1 的 PBO/CSCV 才是**可识别**的那个量。
4. **零假设校准是真的，但它是模拟、不是识别**：两个纯噪音族 6 个组合零平台，这是真证据；
   但它依赖**我自己选的**零假设族（iid 噪音 + 滑动平均噪音），换一个带截面结构的零假设，结论可能不同。

**最讽刺的一点**：仓库**早就有** PBO/CSCV 与 DSR（`src/research/overfitting.py`，实现与
§4.1 一致，且 `print_overfitting` 里已经写了诚实提示“若历史上还试过其他参数/窗口，
请用 `--trials` 声明真实试验次数”），`strategy_suite`、`carry_ranking`、`pairs_study` 都在用。
**我的扫描器把整套现成机制绕过去了，自己造了一个没有理论保证的门槛。**
这正是 de Prado 批评的“研究流程没有质检环节”——不是因为缺工具，是因为没接上。

**结论**：扫描器的**发现**（`vol` > `mom` > `liq` > `dth` 的稳健性排序）可能是对的，
但 **“门槛 2.46”这个数字没有理论保证**，不该被当作“已校正的显著性”来读。
