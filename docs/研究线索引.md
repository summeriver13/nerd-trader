## 五、新增一条线的六件套

按顺序补齐，缺一项就不算「这条线存在」：

1. `src/research/<line>/`——实现，`__init__.py` 只写这个包的边界（一句话），不做法向再导出；
2. `scripts/<line>_study.py`——CLI 薄壳，参数与默认值写在 docstring 里；
3. `docs/<line>/README.md`——口径、读数、**预注册判据**、复现命令、已知限制；
4. `tests/research/test_<line>_*.py`——口径契约测试（不是「跑通」测试）；
5. 本页表格加一行，并在 `README.md` 的研究结论索引加一行判定；
6. 产物落 `data/results/<line>/`，不落顶层（顶层只放跨线对照表）。

## 六、已知索引债

- `docs/factors/README.md` 有 28 节、约 1900 行，是单页承担的十条子线（因子/表示/标签/验证/合成床），
  拆分方式见该页目录；
- `scripts/` 61 个入口之间**没有真重复**（每个都被文档引用、无孤儿），但曾各自重复声明 `--market`/`--timeframe`/`--no-save`
  （五种说法），已收敛到 [`src/utils/study_cli.py`](../src/utils/study_cli.py)，32 个脚本改用；
- `*_report.py`（trend/sampling/labeling/listings/meme 各一）暂未合并进各自包的核心模块，
  先按职责分居、等出现真职责缝再合；
- `__init__.py` 不做法向再导出，调用方一律写全路径（`from src.research.trend.tsmom import ...`），
  避免一层再导出变成第二份需要维护的公共 API。
