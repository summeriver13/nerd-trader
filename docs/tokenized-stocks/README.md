# 代币化股票（tokenized stocks）：口径侦察

本页回答三个问题：OKX 上的「代币化美股」到底有几个产品、各自是什么口径、以及研究前
必须先钉死哪些口径债。

范围依据：容器 ADR-0008（加密交易所上的合成标的算研究范围，但不直接碰美股）。
所有读数取自 **2026-10-17 的一次性探针**（经本机代理直读 OKX 公开端点，无鉴权）。
本页与 [`docs/onchain/README.md`](../onchain/README.md) 同性质：**零代码、零数据落地**，
不涉及任何新依赖、采集代码或数据入库。

## 一、结论速览

- **「代币化闪迪」是两个产品，经济含义相反**：`XSNDK-USDT` 是链上代币现货（**有股息**，
  以 multiplier 再投资成更多份数）；`SNDK-USDT-SWAP` 是 USDT 永续（**无股息**、有资金费）。
  把它们当同一个东西讨论，结论一定错。
- **流动性全在永续**：140 个 xStocks 现货对 24h 名义合计 **$29.0M**，198 个股票永续合计
  **$994.3M**（**34 倍**）；单标的更极端——XSNDK **$1.17M** vs SNDK 永续 **$267.4M**（约 230 倍）。
- **现货代币可以在 OKX 直接交易**（现货区、7×24、0.001 份起 ≈ $1.3、两种下单模式），
  但盘口是玩具级：XSNDK **20 档卖盘累计只有 $10K**，吃穿到 +50bp 也才 $9.9K
  （参照 BTC-USDT 单档卖一就有 $48K）。
- **缺失股息没有被免费补偿**：永续多头拿不到股息，而高股息名字的资金费率是**负**的
  （KO 33 天窗口年化 −5.26%，多头收钱 → 空头付钱），成长/科技名字为正（SNDK 96 天
  **+6.40%**，多头付钱）→ 两个方向都不白拿，缺口被资金费率定价回去了。
- **75x 是营销位**：SNDK 75x 档名义上限只有 **175 USDT**（≈0.13 股）；$1 万名义 ≈10x、
  $2.8 万 ≈5x。全池 198 个标的里 75x 只有 2 个（SNDK、SPCX）。
- **24/7 但周末是死的**：永续周末量占 **2.3%**、小时均 |收益| 0.109% vs 工作日 0.451%
  （1/4）；量集中在美股开盘——13:00 UTC 单小时占 **25.6%**、13–14 点合计约 40%。
- **非交易时段没有外部锚**：指数 1H 在非交易时段的**静止比例为 0/489 根** → 指数不冻结，
  休市时它跟随永续/他处永续价，**±10% 锚定带是唯一硬约束**：休市时你交易的是自我定价市场。
- **样本量是硬约束**：股票永续最老标的 2026-02-25 上市（约 233 根日线），XSNDK 现货
  2026-07-16（约 93 天）→ 这条线的现实定位是**前向积累 + 口径验证**，不是立刻出 alpha。

## 二、两个产品（同一标的、两套口径）

| 维度 | 链上代币现货 `XSNDK-USDT` | 代币化股票永续 `SNDK-USDT-SWAP` |
| --- | --- | --- |
| 入口 | OKX **现货区**（OKX 另有 DEX 通道） | OKX **TradFi / 合约区** |
| 契约 | `baseCcy=XSNDK`、`lotSz=0.000001`、`minSz=0.001`（≈$1.3）、`tickSz=0.1`、上市 **2026-07-16** | `ctVal=1`（1 张 = 1 股）、`ctType=linear`、`settleCcy=USDT`、`tickSz=0.1`、`openType=fix_price`、上市 **2026-03-04** |
| 股息 | ✅ 有，发行方层面再投资 → 持仓**份数**增加 | ❌ 无（官方：TradFi 不支持分红处理，价格也不扣减分红） |
| 资金费 | 无 | 8h 结算，SNDK 实测年化 **+6.40%**（多头付） |
| 杠杆 | 不支持单币种杠杆 | 最高 75x（实际阶梯见 §四） |
| 24h 名义额 | **$1.17M**（`volCcy24h`=1,169,706 USDT） | **$267.4M** |
| 点差 | 3.1bp（盘口 bid 1298.6 / ask 1299.0） | 0.77bp |

XSOXL $1.5M、XSPY $1.3M、**XSNDK $1.17M**、XMU $1.0M。

## 三、现货口径：OKX「统一代币化股票」+ xStocks multiplier

OKX 2026-07-15 上线**统一代币化股票**（Unified Tokenized Stocks），口径以官方帮助页
（`help/unified-tokenized-stocks`，2026-09-18 版）为准：

| 项 | 规则 |
| --- | --- |
| 交易时间 | **7×24**；周末与美股休市时段定价 = 最近收盘价 + 市场估算，**价差扩大、价格保护阈值放宽** |
| 下单模式 | 两种并存：**订单表**（出借匹配，如 XTSLA/USDT）与**买入/卖出/兑换**（确认即时报价） |
| 计价单位 | 以「**份**」计（1 份 XAAPL = 1 股苹果的价格敞口）；充提币时按发行方倍数折算成份 |
| 分红 | **不发现金**：发行方层面再投资 → 份数增加，`新增份数 = 参与分红份数 × (分红后倍数 ÷ 分红前倍数 − 1)`；预扣税已含在 multiplier 里。**分红期间交易与委托不受影响**，只有存币/提币/内部转账暂停数分钟 |
| 充提币 | 支持 **Solana 与 Xlayer** 网络；提币发放的是发行方代币（如 AAPLx），按当时倍数折算 |
| 杠杆/保证金 | ❌ 不支持单币种杠杆；部分资产可作多币种/PM 质押（带折扣率）；**现货持仓暂不能当对应永续的保证金**（分属不同风险单元，官方称后续支持）；暂不支持借贷 |
| 发行方 | **Payward 旗下 xStocks**，每枚 1:1 全额抵押（托管机构持有或代持）；OKX 只做分销与平台运营 |
| 性质 | **不是股票**：不享有股东权益/投票权；Reg S，不向美国人士或受限辖区提供 |

xStocks 的公司行动机制（`docs.xstocks.fi`）：

- 每枚代币起步 multiplier **1.0**（1 枚 = 1 股价值），multiplier 追踪该代币生命周期内**全部**公司行动的累计效应；
- **股息**：托管方收到现金 → **再投资**买入更多同一股票 → multiplier 上调（净扣预扣税），
  持有者余额按比例增加（官方例：AAPL 分红 → multiplier 1.0 → 1.008）；
- **拆股** multiplier ×比例（4:1 → 1.008 → 4.032）、**反向拆股** ÷比例；
- **激活时间：除息日次日 00:30 UTC**，建议交易场所在激活窗口前后短暂暂停交互；
- 链上实现三套：EVM 合约自动调余额；**Solana / TON 链上余额不变**，multiplier 存在
  metadata 里由钱包折算——即「余额」有两种读法，跨链搬运时必须认准。

**官方自陈风险**（值得逐条记）：发行方与托管风险、多发行方后**提币币种不确定**、
休市时段价差扩大、**证券出借**（发行方可能把标的股票借出换成现金质押，其价值未必等于标的）、
**发行方可能提前终止**（终止时收回金额可能低于本金）。

## 四、永续口径（`instCategory=3`）

- **无股息**：多头承担除息价格下跌却拿不到任何补偿；空头免付真实市场必须付的
  dividend compensation 与借券费。缺口只能靠资金费率填（见 §一最后两条）。
- **资金费**：只有基差项（利率 `I=0%`）、8h 结算、7×24；指数为多源复合
  （Pyth/Ondo 实时股价 + 他处股票永续价 + OKX 自身合约价 + Hyperliquid/Binance 指数价，
  非交易时段权重偏向合约价），带 **±10% 锚定带**。
- **杠杆阶梯**（实测 SNDK 跨仓，`/public/position-tiers`）：

  | 最大杠杆 | 名义上限 | 维持保证金率 | 最大杠杆 | 名义上限 | 维持保证金率 |
  | --- | --- | --- | --- | --- | --- |
  | 75x | 175 USDT | 0.65% | 20x | 4,200 USDT | 4.00% |
  | 50x | 350 USDT | 1.00% | 10x | 11,200 USDT | 9.00% |
  | 40x | 700 USDT | 1.50% | 5x | 25,200 USDT | 19.00% |
  | 25x | 2,800 USDT | 3.00% | 2x | 67,200 USDT | 49.00% |

  全池杠杆分布：75x **2 个**（SNDK、SPCX）、50x 12、25x 23、20x 95、10x 65、5x 1。
- **公司行动**：拆并股做**价值中性 rebase**（标记价 ÷比例、持仓数量 ×比例、挂单价与数量同比例
  调整，止盈止损/计划委托/追踪委托全部取消或暂停）；**大额分红 → 直接结算下线**。

## 五、时段与流动性实测（2026-10-17）

SNDK 永续 1H（21 天 600 根）与 XSNDK 现货 1H（同窗口）对照：

| 读数 | 永续 `SNDK-USDT-SWAP` | 现货 `XSNDK-USDT` |
| --- | --- | --- |
| 美股盘中（13:30–20:00 UTC）量占比 | **39.2%** | 45.0% |
| 最集中单小时（13:00 UTC） | **25.59%** | — |
| 周末量占比 | **2.3%** | 3.3% |
| 周末小时均 \|收益\| | 0.109% | — |
| 工作日小时均 \|收益\| | 0.451% | — |
| 零成交 1H bar | 0 | 2 / 600 |
| 指数在非交易时段静止的根数 | **0 / 489** | — |

推论：① 它**不是美股时段的镜像**，但**周末确实是半个死市场**（量与波动都掉一个量级）；
② 量的重心压在美股开盘；③ 非交易时段指数**不冻结** → 指数含永续自身价格，存在
「永续价 → 指数 → 标记价」的反身性，休市时段唯一硬约束是 ±10% 锚定带。

## 六、与「直接持有美股」的差别

| 维度 | XSNDK（现货代币） | SNDK 永续 | 直接持股 |
| --- | --- | --- | --- |
| 股息 | ✅ 但只以**份数**形式再投资，不给现金选择权 | ❌ 完全没有 | ✅ 现金入账 |
| 交易时段 | 7×24（周末极薄） | 7×24（周末极薄） | 9:30–16:00 ET + 盘前盘后 |
| 杠杆 | 无 | 最高 75x（实际 175 USDT 名义） | Reg T 2x / 日内 4x |
| 做空 | ❌ 暂不支持借贷（官方：不支持此类资产借贷） | 直接空，付/收资金费 | 需借券 + 借券费 + SSR 规则 |
| 持有成本 | 无资金费 | **+6.40%/年**（SNDK 多头付） | 无 |
| 权利 | 无投票权 | 无任何权利 | 股东权利 + SIPC |
| 公司行动 | multiplier rebase（份数变） | rebase（数量变）+ 可能下线 | 券商自动处理 |
| 对手方 | 发行方 + 托管 + OKX | OKX（含结算下线风险） | 券商 + 清算所 |
| 最小单位 | 0.001 份 ≈ **$1.3** | 1 张 = 1 股（75x 档 175 USDT 名义） | 整股/碎股 |

一句话：**要股息与股权 → 只有直接持股；要 7×24 与杠杆 → 只有永续（深度是现货的 230 倍）；
要低门槛链上敞口 → XSNDK，但深度只够小额。**

## 七、口径债（动手研究前必须处理）

1. **除息断点**：跨股票横截面若不扣股息率，会把股息率差异误当 alpha。现货侧以 multiplier
   体现、永续侧**完全缺失**，两个池的除息口径不一样。
2. **rebase 断点**：拆并股会让未复权价格序列出现假跳（4:1 → 单日 −75%）；且永续的复权机制是
   **放大持仓数量而非价格复权**，与加密现货池的复权经验不同，直接复用会造出幽灵信号。
3. **资金费率历史保留窗（实测）**：KO 合约 2026-02-25 上市，但费率最早只回 **2026-08-10**
   （205 条 / 68 天）；SNDK 最早回 2026-07-13（289 条 / 96 天）→ **不保证超过约 3 个月**。
   任何费率研究必须先自持落盘，否则样本随时间被静默截断。
4. **现/永两个池价格分裂**：同一时刻 XSNDK 1299.30 vs 永续 1298.40（+0.07%），是两套盘口、
   两套成本、两套公司行动口径；横截面研究必须声明用哪个池。
5. **trials 账本**：新增 198 个永续标的 / 140 个现货对会扩大搜索空间，扫描时 `--trials`
   必须把新增标的数与参数格数一并声明（当前全库 N=7808），不得静默抬高门槛。
6. **数据接入为零**：`src/utils/data_sources/` 目前只有加密永续/现货与强平端点，
   这条线还没有任何采集代码或落地数据。
