# 资金费率 carry：30 只标的的净收益排名与跨源校验

delta 中性 carry（做多现货 + 做空等额永续）常被当成「无风险套利」。框架里已有实现
（`src/research/carry.py`），但它依赖一个**从未验证过的假设**——「费率取 Binance、
执行按 OKX」，因为 OKX 的资金费率接口只保留约 103 天。本页回答两件事：这个跨源
替代的误差有多大、扣掉成本后 carry 还剩多少。

数据：Binance 8h 结算费率 29 只（2019-09 起，154,345 条）；OKX 同口径 30 只
（2026-06-29 起，11,880 条，实测接口上限）。两者重叠 104 天。
工具：`scripts/fetch_funding_history.py`（抓取）、`scripts/carry_ranking.py`（分析）。

（表中只列代表标的，其余 17 只的差异都在 ±2%/年以内，完整数据由脚本输出。）

**结论**：

- **对大盘币，跨源替代成立**：BTC 差 +0.60%/年、ETH +0.46%、SOL +0.09%、
  DOT −0.05%，中位 −0.0142 bp/日折算年化不到 0.06%。
- **对小币不成立**：BAT +7.11%、WLD −5.32%、TRUMP −5.00%、CAP +5.18%——
  这些标的在两所由不同人群定价，日均费率能差 1.4 ~ 1.9 bp，比大盘币的
  carry 本身还大。
- 相关中位 0.713（BAT 0.474、BNB 0.468 最低；CAP 0.994、MET 0.991 最高），
  符号一致率中位约 85%。
- **用法上要区分**：用 Binance 费率研究 BTC/ETH 的 carry 可以，直接套到小币
  会系统性歪掉结论。

（完整 29 行由 `carry_ranking.py` 输出。）

**三条读数**：

1. **carry 收益在系统性衰减**。同一批标的，全历史口径与近 365 天口径差得很远：
   XRP 10.26% → −0.02%、AAVE 10.00% → 1.89%、ETH 9.65% → 1.67%、
   BTC 7.97% → 2.19%、SOL −0.23% → −1.08%。原因是永续市场成熟、套利者变多，
   费率被压向 0。**用全历史年化做决策会严重高估现在的收益。**
2. **近期能做的标的极少**。近 365 天净年化为正的有 14 只，但超过 3% 的只有
   LIT（6.42%，仅 291 天历史）、HYPE（3.79%）、PUMP（3.63%）、MET（3.47%）、
   UNI（3.03%）。头部三个都是上线不足两年的新币——**新币 carry 高，但历史短、
   流动性薄、下架风险高**，这正是「高 carry 从哪来」的答案。
3. **一批标的的费率长期为负**，正向 carry（多现货+空永续）在这些标的上是**付钱**的：
   TRUMP 正费率占比 37.0%、BNB 35.6%、ENA 53.0%；CAP、SAND 的日均费率低到
   −14.2 与 −10.6 bp/日。负费率下要做反向 carry（空现货 + 多永续）就得借币，
   而借币有成本、有被强制平仓的风险——**这一步开始，就不是无风险了**。

## 三、「无风险」的成色

| 风险 | 实测证据 |
| --- | --- |
| **短期逆向波动** | BTC 有 **7.2%** 的 30 天窗口亏钱、ETH 8.2%；SOL 28.2%、ENA 60.5%、TRUMP 80.2%、CAP 76.3% |
| **滚动 P5 很惨** | SOL −34.83%、ENA −39.87%、MAGIC −75.83%、CAP −76.67%（年化口径） |
| **费率方向反转** | BNB 正费率占比仅 35.6%、TRUMP 37.0%——建仓时正费率不代表持有期正费率 |
| **跨源误差** | 小币上 5 ~ 7%/年，比 carry 本身还大 |
| **收益衰减** | 全历史 8 ~ 10% 的标的，近一年只剩 0 ~ 2% |
| **未建模的风险** | 爆仓（永续空头遇暴涨）、交易所风险（提币暂停、ADL）、借币成本（负费率侧） |

一句话：**carry 不是无风险，它是「用小概率大亏损换稳定小收益」**。capital 占用
1.5× 意味着 1 倍名义的 delta 中性仓位实际锁住 1.5 倍资金，年化 2% 对应资本回报
约 1.3%——低于同期无风险利率，还要承担上述全部风险。

## 四、口径与限制

- 收益按日求和（结算间隔 4h/8h 混用时仍可比）；缺日按 0 补齐并计数，缺日多则年化不可信。
- 成本假设：双腿进出 `2×(0.10%+0.05%)`、再平衡 12 次/年 × 5% 换手、资本占用 1.5×，
  均沿用 `src/research/carry.py`，未按标的调整滑点与深度。
- 未建模爆仓、交易所风险、借币成本与下架风险；未做资金费率转负的止损分析。
- Binance 的 PEPE 永续是 1000 倍面值合约（`1000PEPE/USDT`），费率口径相同，已按同标的处理；
  XDP 在 Binance 无对应永续，只在 OKX 侧存在。
- 跨源校验只有 104 天重叠期，且只覆盖一段行情；「小币跨源差异大」的结论样本偏薄。

## 五、复现

```bash
uv run python scripts/fetch_funding_history.py    # 抓两所费率（约 5 分钟，增量补数）
uv run python scripts/carry_ranking.py            # 排名 + 跨源校验表
uv run python research.py --carry --symbol BTC/USDT:USDT --carry-days 2900  # 单标的详细报告
```
